# 素材取り込みと音声分離

制作者は、実況動画に含まれる音声トラック、別に収録した音声ファイル、ゲーム音と声が混ざった音声をプロジェクトに取り込める。実況動画を基準に各トラックの時刻を対応付け、必要ならオフセットを調整できる。

既に分かれているトラックは、ゲーム音や話者音声として個別に扱える。混合音声はユーザーが選んで Windows PC 内で分離し、ゲーム音と各話者の音声をそれぞれ編集可能なトラックにする。分離トラックをプレビューや書き出しで個別に音量調整・ミュートできる。元の録音への参照も保持する。

話者の識別は発話に話者を付ける処理で、音声分離は個別に聴ける音声トラックを得る処理。会話が重なるなど、分離した結果を得られなかった場合は理由を示し、制作者が元の録音で編集を続けられる。 [素材取り込み・音声分離のシナリオ](media-import.feature) · [文字起こしと字幕](transcription.md)
