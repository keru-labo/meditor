# 日本語の文字起こしと字幕

実況素材の音声を Windows PC 内で自動文字起こしする。発話本文、日本語の単語時刻と、識別できた話者を素材に対応付ける。名前が分からない話者は「話者A」などで区別し、制作者が名前を付けられる。

文字起こし結果は AI の編集の手掛かりになる。そこから作った字幕はタイムライン上に表示し、制作者が本文・話者・表示区間を編集できる。素材時刻とタイムライン時刻の対応は、クリップの配置から求める。 [編集用語](../ubiquitous-language.md)

チャットでは時間範囲、音声トラック、全体を指定して文字起こしを追加・再実行できる。範囲とトラックを組み合わせて指定できる。時刻を指定した場合、どの時刻の範囲を使うかが分かる状態で処理し、タイムライン上の指定は対応する素材区間へ結び付ける。

再文字起こしの結果が編集済み字幕に重なる場合は、反映前に警告し、対象の字幕を差し替えるか既存の字幕を残すか選べる。指定外の音声・区間の字幕を保持する。 [文字起こし・字幕のシナリオ](transcription.feature)
