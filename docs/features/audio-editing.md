# 音声編集とミックス

制作者はゲーム音、話者音声、BGM や効果音を個別の音声トラックに配置し、重ねて編集できる。動画に含まれる音声もトラックとして扱い、映像との位置関係を保持したまま移動するか、独立して位置を調整できる。 [素材取り込みと音声分離](media-import.md) · [映像・タイムライン編集](video-timeline.md)

## 区間と音量

- 音声クリップを選択して分割・トリミング・移動できる。元素材は保持する。素材の開始前や終了後、クリップを配置していない時間に、その素材の音は加えない。同じ時間に置いたほかの音声はミックスする。
- クリップ単位とトラック単位で音量を調整できる。クリップの先頭・末尾にフェードイン・アウトを適用し、長さを調整できる。トラックをミュートしても配置や他のトラックの設定は保持する。
- 特定のトラックだけを聴くためにソロにできる。ソロを解除すると、各トラックの音量とミュートを反映した再生に戻る。ソロは試聴用の状態で、書き出しは各トラックの音量とミュートを使う。
- 再生中にトラックごとのレベルとミックス後のレベルを確認できる。無音の区間や、ミックスのピークが上限を超える箇所を確認して音量を調整できる。

## 再生・書き出し・履歴

音声は同じタイムライン時刻の映像・字幕と同期して再生する。ソロ試聴を解除した状態では、プレビューと書き出しが同じ音声クリップの範囲、位置、音量、フェード、ミュートを反映する。映像のない時間も、タイムラインに配置された音声は指定の範囲で再生・書き出しできる。 [動画の書き出し](video-export.md)

GUI とチャットから同じ編集を行い、選択中のトラック、変更した区間や値を確認できる。確定した編集は作業履歴に保存され、保存後の再開や Undo でも該当する設定を復元できる。 [チャットでの編集](chat-editing.md) · [作業履歴](edit-history.md) · [音声編集のシナリオ](audio-editing.feature)
