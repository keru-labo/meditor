# チャットでの AI 編集

制作者はチャットで編集の目的と条件を自然文で伝え、返答を見ながら追加指示できる。実況素材、時刻付きの文字起こし結果、現在のプロジェクトの内容が編集の手掛かりになる。許可された場合は映像・音声も AI サービスに渡せる。 [AI サービスへの接続・送信許可](ai-connections.md)

初回リリースで次の依頼を扱う。

| 依頼 | 利用者から確認できる結果 |
| --- | --- |
| 指定した場面の切り出し | 指示に合う素材区間が編集可能なクリップになる。 [詳細定義](ai-clip-editing.md) |
| 見どころまとめ | 複数の見どころが一つのタイムラインに並び、続けて確認できる。 |
| 投稿用の実況動画 | 指示に沿って無言や待ち時間を詰め、残した場面をつないで字幕付きの動画にできる。 |

AI は指示に応じて、カット、クリップの並べ替え、字幕、ゲーム音・話者の音量、テロップの装飾、ズーム、効果音、縦動画への変換を編集できる。適用できる変更はその場で同じプロジェクトに反映し、制作者は GUI で確認・修正できる。結果と理由をチャットや GUI から確認できる。 [作業履歴](edit-history.md) · [FFmpeg 設定とノード編集](ffmpeg-controls.md)

字幕の「フォントを変えて」「話者ごとに色を変えて」や、映像の「余白を出さず縦長で右側を残して」のような指示では、対象と適用した設定を GUI で確認し、あとから調整できる。 [字幕編集](subtitle-editing.md) · [音声編集](audio-editing.md) · [映像・タイムライン](video-timeline.md) · [映像キャンバス](video-export.md#映像キャンバス)

編集が失敗・中断した場合、途中の変更を残さない。処理中に参照した素材、文字起こし結果、配置先の編集内容が変わった場合、古い前提で作った結果は適用しない。書き出し前に人の確認を待つ条件は、動画の書き出しで定める。 [動画の書き出し](video-export.md) · [AI 編集のシナリオ](chat-editing.feature)
