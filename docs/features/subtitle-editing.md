# 字幕編集とスタイル

制作者は字幕の本文、話者、表示区間、見た目を GUI で編集できる。手入力、文字起こし、字幕ファイルから作成した字幕に同じ操作を使う。AI への指示でも対象と変更内容を指定でき、GUI に同じ編集結果が表示される。 [文字起こし](transcription.md) · [チャットによる編集](chat-editing.md)

## 字幕の配置と本文

- 字幕一覧とタイムラインから字幕を選択し、追加、削除、分割、結合、表示開始・終了の調整ができる。本文の日本語入力、改行、話者の変更に対応する。選択した字幕の表示位置に移動し、映像上で確認できる。
- 素材にひも付けた字幕は、クリップのカットや移動に合わせて対応する発話に追従する。タイムラインに直接置いた字幕は、その配置と対象範囲に従う。複数話者の字幕が同時に存在する場合には、それぞれの本文とスタイルを表示できる。 [タイムライン](video-timeline.md)

## スタイルの編集

| 設定 | GUI とチャットから指定できる内容 |
| --- | --- |
| 文字 | フォント、文字サイズ、太字、文字色 |
| 縁取り | 色と太さ。太さを 0 にすると縁取りを外せる |
| 字幕の背景 | なし、または指定した色と不透明度の背景。既定は **背景なし** |
| 配置 | 水平・垂直方向の位置、揃え、映像端からの余白 |

プロジェクト全体の既定値を決め、必要に応じて話者ごと、または選択した字幕ごとに項目を上書きできる。同じ項目が設定されているときは、字幕、話者、プロジェクト既定の順に使う。複数の字幕を選んでまとめて変更でき、個別指定を外すと上位の設定を継承する。たとえば「話者 A を黄色に、最後の字幕だけフォントを変えて」は、話者 A の文字色と、指定した字幕のフォントだけを変える。

背景なしでは文字と縁取りの周りに長方形を描かず、元の映像が見える。背景を指定した場合は、字幕の領域に選択した色と不透明度を適用する。映像キャンバスの余白は別の設定で調整する。 [映像キャンバス](video-export.md#映像キャンバス)

## 確認・保存・書き出し

- スタイル変更を画面で確認できる。設定したフォントが使えない場合や字形が不足する場合は、利用者に代替を示し、プレビューと書き出しで同じフォント選択を使う。
- プレビューと字幕焼き込み MP4 で、文字色、フォント、縁取り、背景、配置、改行が同じ設定に従う。異なるプレビューサイズでは完成映像に対する相対位置を維持する。画素単位の比較では解像度と圧縮の差を考慮する。
- スタイルはプロジェクトに保存され、開き直しても復元できる。GUI と AI のスタイル変更は同じ履歴を使い、一度の適用でまとめた変更は一度の Undo / Redo で扱う。 [作業履歴](edit-history.md) · [受入シナリオ](subtitle-editing.feature)
