# チャット履歴と作業履歴

会話はチャット履歴として、AI と人が適用した変更は時系列の作業履歴としてプロジェクトに保存する。作業履歴には誰が何を変更したかを記録し、差し戻しでは対象にした変更も参照できる。保存したプロジェクトを開き直すと、両方の履歴を見返してチャットを続けられる。

GUI とチャットの両方から、同じ作業履歴に対して Undo / Redo できる。一つの依頼でまとめて適用した編集は、一つの変更として扱う。たとえば AI がカットと音量をまとめて変えた場合、Undo で両方が戻り、Redo で両方が再適用される。

チャットから「字幕は残して、前のカット変更だけ戻して」のように指示できる。AI が作業履歴から対象を特定し、独立した後続編集を保持したまま、指定された変更を打ち消す操作を新しい履歴として追加する。対象を特定できない場合は確認する。

差し戻す変更に後から行った編集が依存している場合は、その影響を示してから制作者の確認を得る。たとえば、消えるクリップに付いた字幕の扱いを示す。確認を取り消した場合、タイムラインや字幕は現在の状態を保持する。 [作業履歴のシナリオ](edit-history.feature)
