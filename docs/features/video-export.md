# 字幕を焼き込んだ動画の書き出し

どの AI 編集依頼でも、編集結果を反映して字幕を焼き込んだ動画ファイルまで書き出せる。制作者は依頼ごとに、AI が編集後そのまま書き出すか、GUI で確認・修正した後に書き出すかを指定できる。確認を挟む場合は、承認した時点の編集結果を使う。

保存先、ファイル名、画質、縦横比には既定値を持てる。今回の出力先や縦動画などをチャットで指定した場合、その依頼に限って指定値を使う。プレビューと出力は同じクリップの配置、字幕、音量、適用済みのノード構成を反映する。

成功時は出力ファイルの場所を確認できる。失敗時は理由を示し、プロジェクトの編集内容を保持する。字幕の別ファイル出力は、初回リリースでの扱いを別途定める。 [書き出しのシナリオ](video-export.feature)

## 映像キャンバス

- 16:9・9:16 などの完成映像の枠をプレビューし、素材の表示比を保ったまま構図を決められる。**全体を表示**では映像全体を枠に収める。**枠いっぱいに表示**では枠を満たしてはみ出す部分を切り、残す位置を調整できる。
- 余白が出る場合は背景として単色または映像をぼかした背景を選べる。黒は選べる色の一つ。完成映像の枠の外側にある GUI の余白は書き出しに含まれない。 [字幕の背景](subtitle-editing.md#スタイルの編集)
- GUI とチャットで選んだ構図、背景、字幕の位置は、同じ編集版のプレビューと出力に反映する。表示縦横比が画素の縦横比と異なる素材でも、映像を不自然に引き伸ばさず、確認した構図を維持する。 [タイムライン](video-timeline.md)

## 現行プレビュー版での手動書き出し

1. プロジェクトを開き、書き出すクリップの範囲と字幕を調整する。
2. **書き出す**で、画質と縦横比を選ぶ。既定値は標準画質と元の映像の縦横比。
3. **保存先を選ぶ**から、新しい MP4 の保存先を選ぶ。既存のファイルは保持される。
4. 画面下部で結果を確認する。書き出し中も編集を続けられ、進行中の書き出しには開始時点の編集内容と選択した出力設定が使われる。ウィンドウを閉じる操作は書き出し完了後にできる。

画質は標準・高画質・容量優先から選べる。H.264 の CRF は順に 20・18・26。横長 16:9 は 1280 × 720、縦長 9:16 は 720 × 1280 で書き出す。元の映像の表示比を保ったまま画面内に収め、余った部分は黒く埋める。

書き出しには PATH 上の FFmpeg CLI が必要。Windows のビルド手順で指定している FFmpeg SDK の `bin` には、必要な `libx264`、AAC、`libass` を備えた CLI が入っている。字幕の描画にはシステムフォントを使う。

現行の出力形式は H.264 の MP4。プロジェクトに登録した WAV はプレビューと同じオフセット・ゲインでミックスして AAC にする。登録 WAV がないプロジェクトは映像のみを書き出す。字幕をタイムラインの位置で映像へ焼き込む。プレビューには表示中の映像フレームに対応する字幕を重ねる。開始時刻を含み、終了時刻を含まない。重なった字幕は本文を順に表示する。映像を見ながら確認できるように表示領域の高さに上限を設ける。書き出しには開始時に適用済みのプロジェクト全体の字幕スタイルを使う。フォントの代替、行の配置、字幕の時刻精度はプレビューと異なる場合がある。映像の切り出しと字幕の表示は、FFmpeg の出力フレームと字幕時刻精度に従う。 [字幕スタイル](subtitle-editing.md#プレビュー版で使える設定)

## 現行プレビュー版で AI の提案から書き出す

1. **AI 編集**で、残したい場面と書き出し設定を伝える。たとえば「最初のボス戦の感想を字幕付きの縦動画にして、高画質で書き出して」と依頼する。
2. 選ばれた区間をプレビューし、必要に応じて範囲や字幕を修正する。**書き出し設定を確認**を押すと、提案された画質と縦横比が設定画面に表示される。指定がない項目は標準画質または元映像の縦横比を使う。
3. 設定を確認または変更してから、**保存先を選ぶ**で新しい MP4 のパスを指定する。保存先を確定すると、開始時点の編集内容を使って書き出す。設定画面や保存先の選択をキャンセルすると、編集内容を保持する。

AI が区間選択に使った字幕は、書き出す区間と重なる部分を切り出し、その区間の先頭を 0 秒として焼き込む。対応する字幕本文を GUI で直してから書き出すと、修正後の本文が使われる。 [素材時刻とクリップの対応](ai-clip-editing.md#エディターでの試用)

提案は依頼時のプロジェクトを開いている間に使える。別のプロジェクトを開くか、提案のクリップを元に戻すと破棄される。通常の **書き出す** は標準画質と元映像の縦横比で設定画面を開く。Codex が返すのは区間と対応済みの設定候補までで、出力先を確定して実際に書き出しを始めるのは制作者。 [Windows での確認手順](../ai-selection.md#書き出しまで確認する)
