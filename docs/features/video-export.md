# 字幕を焼き込んだ動画の書き出し

どの AI 編集依頼でも、編集結果を反映して字幕を焼き込んだ動画ファイルまで書き出せる。制作者は依頼ごとに、AI が編集後そのまま書き出すか、GUI で確認・修正した後に書き出すかを指定できる。確認を挟む場合は、承認した時点の編集結果を使う。

保存先、ファイル名、画質、縦横比には既定値を持てる。今回の出力先や縦動画などをチャットで指定した場合、その依頼に限って指定値を使う。プレビューと出力は同じクリップの配置、字幕、音量、適用済みのノード構成を反映する。

成功時は出力ファイルの場所を確認できる。失敗時は理由を示し、プロジェクトの編集内容を保持する。字幕の別ファイル出力は、初回リリースでの扱いを別途定める。 [書き出しのシナリオ](video-export.feature)
