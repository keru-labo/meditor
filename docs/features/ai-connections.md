# Codex App Server への接続と素材の送信許可

AI チャットの初回接続先は Codex App Server。Codex CLI の ChatGPT ログインを使用する。ログインが必要な場合はセットアップ方法を案内する。 [Codex のセットアップ](../ai-selection.md)

現在の区間選択では、制作者が送信を選ぶと、編集指示と時刻付き字幕を Codex に渡す。送信操作の近くで送信内容が分かる。動画、音声、プロジェクトと素材へのパスは送信対象外。

今後、別サービスや映像・音声入力を追加する場合は、各接続先の公式仕様で入力を検証する。外部に映像・音声を渡すには、送信先とデータ種別を特定した設定上の許可が必要。許可を取り消すと、以後の該当データの送信を止める。

メディアの取り込み、自動文字起こし、話者識別、音声分離、FFmpeg による編集と書き出しは Windows PC 内で実行する。 [Codex 接続のシナリオ](ai-connections.feature)
