# AI サービスへの接続と素材の送信許可

AI チャットの接続先候補は ChatGPT、Gemini、Claude Code。既存のログインや CLI を利用する方式と、API キーを設定する方式を対象にし、各サービスで公式に利用できる方式を設定画面に表示する。サービスごとの接続方式、利用条件、利用できる入力は公式仕様を確認して確定する。

プロンプト、時刻付き文字起こし、編集情報に加え、必要な場面の映像や音声を判断材料にできる。映像・音声を外部に送るには設定で送信先への許可が必要。許可後は依頼に応じて送信でき、設定で許可を取り消すと以後の送信を止める。接続方式が入力を扱えない場合や許可がない場合は、その理由を示す。

メディアの取り込み、自動文字起こし、話者識別、音声分離、FFmpeg による編集と書き出しは Windows PC 内で実行する。 [AI サービスへの接続・送信許可のシナリオ](ai-connections.feature)
