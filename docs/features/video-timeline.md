# 映像・タイムライン編集

制作者は複数の映像、音声、字幕を一つのタイムラインに配置し、再生順や重なりを指定できる。クリップは素材の範囲とタイムライン上の位置を持つ。クリップを加工・削除しても元素材は保持する。 [編集用語](../ubiquitous-language.md)

## トラックとプレビュー

- 複数の映像トラックにクリップを置き、上位トラックの映像を下位トラックへ重ねられる。透明部分からは下位の映像が見える。各映像の大きさや位置を調整して、全画面や小窓にできる。
- 音声トラックと字幕は映像と同じプレイヘッドに従う。映像が存在しない時間はキャンバスの背景を表示し、その時間に配置した音声や字幕は再生する。 [音声編集](audio-editing.md) · [動画の書き出し](video-export.md)
- クリップを一つ、または複数選択し、拡大・縮小したタイムラインで境界を確認できる。シークやスクラブでは指定位置に重なる映像、字幕を確認できる。再生を再開するとその位置から映像・音声の同期を保つ。

## 編集操作と同期

- 選択したクリップをプレイヘッド位置で分割し、開始・終了をトリミングできる。分割点の前後で素材の位置が連続し、トリミングは参照する素材の範囲内で行う。
- クリップをタイムライン上で移動・並べ替え・削除できる。移動とトリミングでは、プレイヘッドや他のクリップ境界に吸着させてそろえられる。吸着を外して任意の位置にも編集できる。
- 削除や短縮で空いた時間を保持するか、リップル編集で詰めるかを選べる。リップル編集では対象を指定し、後続のクリップや字幕を空いた時間だけ前へ移動する。移動対象外のトラックは既存の位置を保つ。対象間の重なりや衝突で編集できないときは、影響が分かるようにして編集前の状態を保つ。
- 映像と同期している音声や字幕は一緒に動かせる。独立して配置した項目の時刻は制作者が変更を指定するまで保持する。

## 映像の調整と切り替え

- クリップごとに位置、拡大率、切り抜き範囲を調整できる。再生速度を変更したときはタイムライン上の長さが変わり、ひも付いた音声と字幕も変更後の時刻に従う。
- クリップ間の切り替えはカットまたはトランジションから選べる。クロスフェードでは対象のクリップと長さを確認できる。素材の範囲内で指定した長さを確保できないときは、その箇所を示して適用前の状態を保つ。
- 映像と字幕の配置や処理を完成映像の枠で確認する。色などの映像処理や複数の処理の組み合わせは編集対象を指定して適用する。 [映像キャンバス](video-export.md#映像キャンバス) · [FFmpeg 設定とノード編集](ffmpeg-controls.md)

GUI とチャットから同じ操作を行える。一度に確定した編集は、関連する項目の変更も含め作業履歴に保存され、まとめて元に戻せる。保存した状態で再生すると、同じ配置、同期関係、重なりを使う。 [チャットでの編集](chat-editing.md) · [作業履歴](edit-history.md) · [タイムラインのシナリオ](video-timeline.feature)
