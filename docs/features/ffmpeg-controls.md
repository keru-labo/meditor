# FFmpeg 設定とノード編集

配布する FFmpeg で利用可能なフィルター、コーデック、出力形式と各設定項目をすべてカタログに載せ、専用画面から選択・入力できる。利用可能な機能は配布する FFmpeg の構成で決まる。値は項目の型や選択肢に沿って指定する。設定項目の選択だけで変更を完結できる。

チャットでは「声を聞きやすくして」といった目的も、「話者Aに `loudnorm` を適用して」といったフィルター名、適用先、設定値の明示も使える。チャットから変更した設定は専用画面で確認・修正でき、そこから行った変更も同じプロジェクトと作業履歴に反映する。

ノード画面では、映像・音声の入力、処理、出力を結ぶ。処理を順番に並べ、分岐と合成を組める。たとえば、映像を分けて片方を拡大し、元の映像に小窓として合成できる。音声ではゲーム音と各話者を個別に調整してからミックスできる。AI が作った処理もノード画面で確認・修正できる。

処理に必要な接続や値が揃わない場合は、問題のある項目を示し、適用済みの有効な編集状態を保つ。プレビューと書き出しは同じ適用済み設定・ノード構成を反映する。 [FFmpeg 設定・ノード編集のシナリオ](ffmpeg-controls.feature)
