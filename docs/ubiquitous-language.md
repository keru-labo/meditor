# meditor のユビキタス言語

AI と人が同じプロジェクトを編集する場面で、GUI、機能定義、BDD に使う用語を揃える。用語の意味を具体化したときに解釈の違いが見つかったら、この用語集と関係する製品要件を見直す。 [製品要件](requirements.md)

## AI と人による編集

| 用語 | 定義 |
| --- | --- |
| プロジェクト | 素材への参照と、タイムラインや字幕などの編集内容をまとめた作業単位。保存して開き直し、AI と人が同じプロジェクトで編集を続けられる。 |
| 編集指示 | AI に渡す編集の目的や条件。対象区間や残したい内容などを指定する。 |
| 編集操作 | AI または人がプロジェクトの編集内容を変える行為。クリップを移動する、字幕の本文を直すなどが該当する。 |
| 編集結果 | 編集操作がプロジェクトに反映された後の内容。GUI で確認・修正でき、プレビューと書き出しに反映される。 |

## 音声から得た発話と字幕

| 用語 | 定義 |
| --- | --- |
| 自動文字起こし | 音声から発話の本文と単語時刻を取得する処理。 |
| 文字起こし結果 | 音声から得た発話の本文と、素材時刻に対応する単語時刻。AI が編集に利用する情報になる。 |
| 字幕 | タイムライン上の表示区間と本文を持つ編集対象。文字起こし結果をもとに作成でき、GUI で本文や表示区間を修正できる。 |

文字起こし結果は「素材のどこで何を話したか」を表す。字幕は「編集後の動画のどこで何を表示するか」を表す。

## 素材とタイムラインの時刻

| 用語 | 定義 |
| --- | --- |
| 素材 | プロジェクトで使う元の動画や音声。実況動画、ゲーム音、話者の収録音声などが該当する。 |
| タイムライン | 素材の区間や字幕を配置し、編集後の再生順と位置を表す時間軸。 |
| クリップ | 素材の区間をタイムラインに配置した編集対象。素材側の区間と、タイムライン側の配置位置を持つ。 |
| 素材時刻 | ひとつの素材の先頭からの位置。元動画の区間や、収録音声内の発話を指すときに使う。 |
| タイムライン時刻 | タイムラインの先頭からの位置。クリップの配置、字幕の表示、再生位置を指すときに使う。既存の設計書でいう「プロジェクト時刻」に当たる。 |
| シーク | タイムライン上の指定位置に再生位置を移す操作。 |
| スクラブ | プレイヘッドを連続して動かし、その位置の映像を確認する操作。 |
| プレイヘッド | タイムライン上で再生位置やスクラブ中の操作位置を示す目印。 |

元動画の素材時刻 30 秒から始まるクリップを、等速でタイムライン時刻 12 秒に配置したとする。クリップの中の素材時刻 33 秒はタイムライン時刻 15 秒に当たる。素材時刻 33 秒の発話をこのクリップで表示する字幕にする場合、表示位置はタイムライン時刻で指定する。
