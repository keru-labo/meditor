# プレビュー基盤の受入条件

## 自動テスト

| Scenario | Given | When | Then |
| --- | --- | --- | --- |
| `empty-slot` | シーク要求がない | 保留要求を取り出す | 値がない |
| `latest-wins` | 同じ送出周期内 | 50、990、120 ms の順に要求する | 120 ms だけを送出対象にする |
| `consume-once` | 保留要求を取り出した | もう一度取り出す | 値がない |
| `clamp-position` | 再生区間が決まっている | 区間外の時刻を要求する | 先頭または末尾に丸める |
| `zero-is-a-target` | シーク可能 | 0 ms を要求する | 0 ms を送出対象にする |
| `cancel-pending` | 要求が保留中 | 保留要求を取り消す | 以前の要求が残らない |
| `accept-after-cancel` | 保留要求を取り消した | 新しい要求を登録して取り出す | 新しい要求を取得する |

停止、素材切替、再生エラーで Qt アダプターが保留要求を取り消す。ドラッグ終了時と再生開始直前はタイマーを待たずに保留要求を送出する。自動テストは要求スロットを検証する。

## GUI での確認

- 音声付きローカル動画を開いた状態で、再生、ポーズ、停止、先頭・中間・末尾へのシークを操作する。映像と再生位置が更新されることを確認する。
- 停止中に中間位置までドラッグする。音声を再生せず、その位置の映像を表示することを確認する。
- 音量変更とミュートを操作し、出力音声で反映を確認する。破損した動画を開き、エラーが表示されることを確認する。
- プレビューを再生中に一方向と往復のドラッグを行い、手を離した位置に映像と再生位置が追従することを確認する。送出済み要求に由来する古いフレームや音声の有無も記録する。

Windows の性能比較条件は [計測設計](performance.md) を参照。
