# エディターの画面と操作

初回リリースで使う画面、主要なボタンと、状態に応じた振る舞いを定める。中心となる流れは、チャットで編集を依頼し、タイムラインに反映し、GUI で修正・差し戻しを行い、書き出すところまで。機能名と条件は [機能定義と BDD](../features/README.md)、編集版と履歴の扱いは [編集ドメイン設計](editing-domain.md) に対応する。

## 画面構成

```text
 プロジェクト     元に戻す / やり直す              履歴    書き出し    設定
 ┌──────────────┬──────────────────────────────┬──────────────────────┐
 │ 素材・トラック │ プレビュー・再生操作           │ チャット              │
 │ 字幕一覧       │ タイムライン・クリップ・字幕    │ 返信・確認・入力欄     │
 └──────────────┴──────────────────────────────┴──────────────────────┘
                  選択したクリップ / トラック → 編集設定・FFmpeg・ノード
```

- チャットとタイムラインを同じ編集画面で参照できる。チャットに処理の状態と反映結果を表示し、対象へ移動できる。
- 素材欄で素材や音声トラックを選ぶ。字幕欄で本文・話者・表示区間を確認して編集する。タイムラインではクリップの選択、移動、順序と範囲の変更、プレビュー位置の指定を行う。
- 対象の処理設定を FFmpeg 設定またはノード画面で開く。選択したクリップやトラックが分かる表示にして、設定後は同じプロジェクトのタイムラインから確認できる。
- 履歴と書き出しは編集画面から開く。設定には Codex の接続状態と書き出しの既定値を置く。

## チャットとタイムライン

| 操作・ボタン | 利用できる条件 | 結果や表示 |
| --- | --- | --- |
| 新規 / 開く | 編集画面を起動している | 新しいプロジェクトを作るか、保存済みのプロジェクトと履歴を開く。保存していない変更があれば判断を求める。 |
| 保存 | プロジェクトを開いている | 現在の編集状態と履歴を保存する。失敗時は編集内容を保ち、理由を表示する。 |
| 送信 | プロジェクトを開き、指示を入力した | 指示を受付済みとして表示し、必要に応じて処理中に切り替える。対象素材や接続方式が必要であれば理由を示す。 |
| 中断 | 対象の依頼が処理中 | その依頼を中断済みと表示する。後から結果が届いても反映しない。 |
| タイムラインで確認 | 依頼の結果が適用され、該当する編集対象を参照できる | 対象クリップなどを選び、対応する位置へ移動する。 |
| 再生 / 一時停止 | プレビューできる素材または編集状態がある | 再生状態を切り替え、プレイヘッドを更新する。 |
| クリップを移動・並べ替え | タイムライン上のクリップを選んでいる | 変更先が有効であれば配置を更新する。変更できない場合は対象と理由が分かる。 |
| 区間を適用 | クリップを選び、開始・終了を入力した | 有効な素材区間を編集として適用し、タイムラインとプレビューに反映する。無効な値を示し、現在の区間を保つ。 |
| 字幕を編集 | 字幕が選択されている | 本文、話者、表示区間を変更できる。反映した編集は作業履歴に入る。 |
| 差し替える / 既存の字幕を残す | 再文字起こしの結果が編集済み字幕に重なり、確認待ちになった | 警告と対象範囲・音声トラックを示す。選んだ内容で対象範囲を処理し、対象外の字幕を保持する。 |

チャットの結果表示は、編集の状態に応じて **処理中、適用済み、確認待ち、中断済み、適用できなかった状態**を区別する。適用できないときは理由を表示する。AI の編集は適用できればタイムラインに反映し、画面を閉じてもチャットと履歴から確認できる。 [チャット編集](../features/chat-editing.md) · [文字起こし](../features/transcription.md)

## 履歴・処理設定・素材

| 画面・操作 | 利用できる条件 | 結果や表示 |
| --- | --- | --- |
| 元に戻す / やり直す | それぞれに該当する操作がある | GUI とチャットで共通の履歴を使用し、操作単位で編集を戻す、または再適用する。 |
| 履歴を開く | プロジェクトを開いている | 人・AI の変更を時系列に並べ、対象、実行者、関連するチャットを表示する。 |
| 影響を確認して続行 / キャンセル | チャットで依頼した差し戻しに、確認が必要な後続編集がある | 影響を受けるクリップや字幕と変更内容を表示する。続行では表示した内容を反映し、キャンセルでは現在の編集を保つ。 |
| FFmpeg 設定を開く / 設定を適用 | 対象の編集状態がある / 入力値と適用先が有効 | フィルター、コーデック、出力形式と各設定項目を選べる。適用後はチャット、設定画面、プレビューから同じ状態を参照する。 |
| ノードを追加・接続 / 構成を適用 | 編集対象を開いている / 必要な接続と設定値が揃う | 映像・音声の処理の順序、分岐、合成が見える。不正な端子や設定値を指し示し、有効な構成を反映する。 |
| 素材を追加 / 音声分離を実行 | プロジェクトを開いている / 混合音声を選んでいる | 動画・音声トラックを追加できる。音声分離ではローカル処理の状態を表示し、成功すると生成したトラックが選択できる。 |
| Codex 接続 | 設定を開いている | 接続状態とログイン方法を表示する。 |

## 書き出し

| 操作・ボタン | 利用できる条件 | 結果や表示 |
| --- | --- | --- |
| 書き出しを開く | 書き出せる編集対象がある | 保存先、名前、画質、縦横比、字幕の焼き込みを確認できる。今回の依頼の値と普段使う設定を区別する。 |
| そのまま書き出す | AI への依頼時に、このモードを指定した | 編集が適用できたら書き出しを開始し、チャットで状態を確認できる。追加の承認は求めない。 |
| 確認してから書き出す | AI への依頼時に、このモードを指定した | AI の編集後に確認待ちを表示する。承認するまでタイムラインで調整できる。 |
| 書き出す | 出力設定と書き出し対象が有効。確認待ちの場合は対象の編集版が表示されている | 確認した編集版を使い、書き出し中と表示する。字幕を焼き込んだ動画を出力する。 |
| 保存先を開く / 再試行 | ジョブが完了 / 失敗した | 完了時は出力ファイルの場所が分かる。失敗時は理由を表示し、保存先などを修正して再試行できる。 |

画面構成とボタン名は設計の初版。詳細な見た目とキーボード操作は、操作の実装と合わせて決める。 [書き出しの BDD](../features/video-export.feature) · [履歴の BDD](../features/edit-history.feature)
