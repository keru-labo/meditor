# ADR 0002 編集・プレビューの起動経路を Rust 版に切り替える

## 状態

採用。Windows の GPU 高速経路と実機評価は継続。

## 背景

[ADR 0001](0001-rust-windows-editor.md) で Rust を採用し、シーク制御を先に実装した。次の段階ではプロジェクトを開いて編集・保存し、音声付きでプレビューする通常の起動経路を Cargo 版に移す。

## 決定

- Slint の winit バックエンドとソフトウェアレンダラーを採用する。字幕一覧は表示行を仮想化し、編集は行の選択とは独立したテキスト欄で行う。配布時の Slint 表示にはアプリ内の AboutSlint を使う。[Slint ライセンス条件](https://slint.dev/terms-and-conditions)
- FFmpeg のソフトウェアデコードと SDL2 のキュー再生を移植後の基準にする。デコードと RGB 変換を専用ワーカーで実行し、GUI には共有ピクセルバッファを渡す。複数音声の PCM を Rust で合成し、消費サンプル数から再生位置を取る。
- Rust 版を通常のビルドと Windows CI の撮影対象にする。比較用の C++ 版は [切り替え直前の main](https://github.com/keru-labo/meditor/tree/28deea9ee56d9b390152ad7868ee9565889634a1) からビルドできる。
- JSON の version 1 / 2 を読み書きし、既存のクリップ、字幕と話者、音声オフセットとゲインを引き継ぐ。保存時は同じフォルダー内の一時ファイルを使って置き換える。

## 検証

CI では字幕10,000件と音声3本の合成プロジェクトで元動画の再生、プロキシの最新シーク、元動画と音声での再開を確認する。Rust 版の Windows プレビューを PR のコメントに表示する。Windows 実機での日本語 IME、表示 p95、物理 A/V 同期、D3D11 テクスチャの共有は [性能計測](../performance.md) の項目として扱う。
