# ADR 0003 Codex App Server を AI 編集の接続先にする

## 状態

採用。

## 背景

AI 編集の接続を先に一つに絞り、制作者の認証とモデル接続を公式クライアントに任せる。初期の用途は時刻付き字幕を手掛かりにした区間選択。

## 決定

- Codex CLI を標準入出力の App Server モードで起動し、専用フォルダーに保存された ChatGPT ログインを Codex に管理させる。GUI からは編集指示と字幕を渡し、プロトコル、認証の確認、バージョン互換性は Rust の接続モジュールに閉じ込める。
- 編集指示は送信操作を起点に一時スレッドへ渡す。作業ディレクトリを素材から分離し、ツールと環境へのアクセスを無効にする。編集対象と結果の有効性はエディターが判断する。
- 制作者が使える接続は Codex App Server に限定する。別のサービスや映像・音声入力を追加するときは、接続先の入力と送信許可を機能定義に反映する。

互換バージョン、ログイン手順、実行制限は [区間選択ガイド](../ai-selection.md) に記載する。
