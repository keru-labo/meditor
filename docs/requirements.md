# meditor の製品要件

## 製品の対象

meditor は、AI がゲーム実況動画を編集する Windows 専用のデスクトップアプリである。実況動画、ゲーム音、複数話者の音声を、ひとつのプロジェクトで扱える。

## 編集の原則

- AI は動画編集を実行し、結果を編集可能なプロジェクトに反映する。
- 人は GUI で直接編集できる。AI が行った編集も同じ GUI で確認・修正できる。
- 日本語の音声を自動で文字起こしし、単語の時刻を素材の音声に合わせる。文字起こし結果は AI 編集に利用でき、人が字幕として修正できる。
- 編集結果をプレビューし、保存したプロジェクトを開き直して編集を続けられる。編集後の動画と字幕を書き出せる。動画の書き出しでは字幕を焼き込める。プレビューと書き出しは同じ編集内容を反映する。

## 操作と再生の原則

- 字幕10,000件を含むプロジェクトでも、一覧の選択や字幕の編集に速やかに応答する。
- 連続スクラブでは映像が最新の操作位置に速やかに追従し、古いシークの映像や音声が後から出力されない。
- スクラブ後に再生を再開すると、確定した位置から元動画と複数の音声が同期して再生される。プレイヘッドは再生位置に追従する。
