# Z3 によるタイムライン時刻の検証

Z3 をタイムラインの整数演算に試験導入する。字幕や動画のファイルを使わず、有効な入力の範囲全体から反例を探せる。検証にはアプリの外で SMT-LIB と Z3 CLI を使う。

## 検証対象

- 長さが正で終端が24時間以下のクリップと、有効なスライダー入力（0〜1,000,000）を扱う。スライダーから求めた時刻はクリップ内に収まり、最大値だけが終端に到達する。
- スライダーと時刻の変換に使う乗算は `i64` に収まり、表示するプレイヘッドの値も `i32` に収まる。
- クリップの区間を変更すると、現在の素材時刻を新しい区間の開始・終了の間に収める。デコーダーに送る際は、素材とクリップのうち小さい終端より手前へクランプする。

時刻の上限と有効区間の条件はプロジェクトモデル、プレイヘッドと素材時刻の変換式はエディター、デコーダーのクランプはプレビュー実装に対応する。 [プロジェクトモデル](../../rust/src/project.rs) · [エディター](../../rust/src/main.rs) · [プレビュー](../../rust/src/video.rs)

モデルは実装から独立した式を使う。式や定数を変更する際はモデルも確認する。Z3 が扱うのはモデルの整数演算で、Slint の入力座標の丸め、Rust の処理全体、FFmpeg が返すフレームの時刻は別途検証する。

## 実行

Debian 13 または Debian 13 の WSL 環境で実行する。CI は Z3 の Debian パッケージ `4.13.3-1` とコンテナイメージのダイジェストを固定している。

```sh
sudo apt-get install z3=4.13.3-1
sh verification/z3/check.sh
```

先に入力条件の充足可能性（`sat`）を確認し、その後に各性質の否定が充足不能（`unsat`）であることを確認する。反例、タイムアウトによる `unknown`、ソルバーエラーはチェック失敗になる。
